# بنك تدريب Traffic & Operations

افتح `index.html` بمتصفح حديث. الصفحة تعمل محليًا ولا تحتاج اتصالًا بالإنترنت.

- لا توجد إجابات مفترضة من أوراق المتقدمين. الإجابة لا تُضاف إلا بعد التحقق من وثيقة تشغيلية معتمدة.
- النتائج والأسئلة المستوردة تحفظ على الجهاز نفسه.
- استخدم **تحديث البنك** لتصدير أو استيراد ملف JSON، أو لأخذ نسخة احتياطية كاملة.
- الأسئلة ذات العناصر البصرية غير المكتملة مستبعدة من التصحيح الآلي.
- النص الناقص يُوسم `Unclear in source` بدل تخمينه.
