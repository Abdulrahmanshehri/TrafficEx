# بنك تدريب Traffic & Operations

افتح `index.html` بمتصفح حديث. الصفحة تعمل محليًا ولا تحتاج اتصالًا بالإنترنت.

- يدخل المتدرب بأي اسم مستخدم، وكلمة المرور هي `123456`.
- اختيارات كل مستخدم ونتائج محاولاته تحفظ على الجهاز والمتصفح نفسه.
- يمكنك الضغط على الاختيار المحدد مرة ثانية أو زر **مسح الإجابة** للتراجع عنه.
- مفتاح الإجابات منفصل عن صفحة السؤال.
- لفتح لوحة التحكم افتح `admin.html`، أو أضف `?admin` إلى نهاية رابط `index.html`.
- بيانات الإدارة: اسم المستخدم `admin` وكلمة المرور `123456`.
- من لوحة التحكم يمكن إضافة الأسئلة وتعديلها وحذفها وتحديد الإجابة الصحيحة وإغلاق صفحة التدريب مؤقتًا.

هذه النسخة HTML ثابتة؛ لذلك الأسئلة المعدلة والدرجات وإغلاق الموقع تحفظ محليًا، ولا تنتقل تلقائيًا بين الأجهزة المختلفة.
